Instalação GitHub

Como usar este arquivo como sistema web.

1. Crie o repositório v4-crm-bridge.
2. Salve este arquivo como index.html.
3. Ative GitHub Pages em Settings → Pages → main/root.
4. Use modo demo para validar com accounts.
5. Depois conecte backend seguro para API real.
Nunca coloque tokens reais no GitHub ou neste front. Use .env, Vercel Env, Apps Script Properties ou Secret Manager.
