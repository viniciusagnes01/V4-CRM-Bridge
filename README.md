# V4 CRM Bridge

Sistema web interno para conectar CRMs ao GrowthPack e alimentar a aba BASE_CRM.

## Escopo

- Accounts
- Clientes e projetos
- Integracoes CRM
- Mapeamento BASE_CRM
- Sincronizacao
- Auditoria
- Logs
- Configuracoes

## Segurança

Credenciais reais nao devem ficar no front-end nem no repositorio. O front usa apenas identificadores de credencial. A credencial real deve ficar em ambiente seguro no backend.

## Publicacao

Ative GitHub Pages na branch V4-COMPANY usando a pasta raiz.
